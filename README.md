# Motion Graphics Projects

이 저장소에는 키네틱 타이포그래피 모션 그래픽 결과물과 브라우저 기반 제작 파일이 들어 있습니다.

## 11월, 천천히 물드는 마음

- `11월_천천히_물드는_마음_9x16.mp4` — 10초, 세로 9:16 영상
- `11월_천천히_물드는_마음_9x16.webm` — 브라우저 렌더링 원본
- `index.html` — 영상 장면과 오리지널 배경음악을 생성하는 인터랙티브 제작 파일

## Korean Air: Anywhere is Possible

- `대한항공_Anywhere_is_Possible_30초_16x9.mp4` — 30초, 1920×1080 가로 영상
- `korean_air_promo.html` — 박자에 반응하는 타이포그래피와 오리지널 음악을 생성하는 제작 파일

대한항공 영상은 공식 홈페이지의 브랜드 표현과 캠페인에서 영감을 받은 콘셉트 시안이며, 대한항공의 공식 광고물은 아닙니다.
